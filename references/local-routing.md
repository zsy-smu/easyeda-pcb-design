# 局部固定线宽避障布线：把“走不通”反馈给布局

适用明确的一对焊盘、两层、已校准完整几何。此工具补充AI Bridge的画线原语，不是一次完成整板的自动布线器。

```powershell
python scripts/plan_local_route.py ROUTE_INPUT.json --out ROUTE_CANDIDATE.json
```

输入共用[地铜工具的几何合同](ground-tool.md)，示例见[geometry-input.json](../assets/examples/geometry-input.json)。改为`schema=easyeda-local-route-input/v1`，保留unit/sourceRevision/board/copper/holes/keepouts/clearanceByNet/edgeClearance；另提供：

```json
{"net":"5V", "fromPadId":"J1.1", "toPadId":"J2.1",
 "width":0.8, "grid":0.25, "viaDiameter":0.8, "viaHole":0.3,
 "viaCost":3, "viaDrillToSmdClearance":0.2, "viaHoleToHoleClearance":0.25,
 "maxExpanded":40000, "maxGridNodes":2000000}
```

这些是接口字段示例，不代表5V或大电流应使用该宽度/过孔。线宽和孔应由本板电流、温升、铜厚/制造及封装决定。`viaCost`是长度代价（mm），控制候选偏好，并非电气via电阻；maxExpanded和grid限定计算预算。不要凭网络名称正则猜电流或线宽。

## 算法实际做什么

1. 外来铜按明确网络净距膨胀，孔/槽、机械和隔离空间按两面处理。PTH的环铜应在两面copper中存在，孔本身也单列；不能把异网通孔当作只在顶层的障碍。
2. 在板框范围内建立两层八邻域网格，端点精确保留真实pad中心，用合法短段接到附近网格。每条边用指定线宽的实际缓冲多边形检查，不能只检查中心线。
3. 换层只有当完整via铜盘在两面均满足净距/板边，钻孔到所有SMD焊盘和既有孔分别满足显式退让时才允许，输出实际via。同网SMD也不能默认钻进去。当前不支持via-in-pad和自动复用既有PTH；没有空间时不穿越，也不自动退成窄线。
4. 在maxExpanded内进行A*搜索；找到后再次检查输出的每一段和每颗via。**不移动器件、不拆旧线、不自动换宽、不写EDA**。

返回0是`CANDIDATE`，1是`BLOCKED`，2为输入/依赖不支持。候选保持原width，`widthFallbackUsed=false`。阻挡原因区分端点出口、预算耗尽、固定网格/线宽无路径；网格无路径不是连续几何上无解的证明。不要看到BLOCKED就减小电源线宽；先看具体功能组是否挡住出口/层间via、局部布局是否需要调整，再决定一次有依据的候选。

新生成via之间也必须满足孔边距。当前在整条路径产生后做两两检查，冲突返回`BLOCKED/via_pair_clearance`，不会保留不合格候选；它没有把全部历史via集合加入A*状态穷举其他路线，必要时调整功能组/允许走廊后重算。

## 一块完整板怎样推进

- 先人工规划/确认电源、开关、驱动、反馈/采样与去耦的**端点、返回路径及禁走区域**，保存为固定种子铜。最短路不能替代开关环路或Kelvin取样。
- 用每次最新完整铜快照生成一条普通连接候选。接受后把它的track/via纳入下一次输入；不能把多条各自在空板上得到的路线一起写回，它们会彼此撞线。
- 同网多点用明确的分支方案拆解，分别检查实际所有焊盘是否同一铜分量。现有同网铜允许重叠，但工具不会因为网名相同就认为两块铜已接通。
- 对功率宽线检查端子/焊盘出口、过孔环铜、辐条与唯一细颈；此工具没有为整条电流路径作热或载流批准。差分、高速阻抗、HDI和特殊过孔不在支持范围。
- 写入前复核sourceRevision；新线少量写、读回路径/层/宽/网/孔，再删除**确认被替代**的旧分支。最后重建地铜、导出实际铜并检查，原生DRC一起验收。

## 局部改板事务

记录`受影响器件ID → 物理pad → 相关走线/孔/铜区ID`，并保存未修改部分的规范几何摘要。联合重排器件时先做本体/使用空间检查，再解引脚出口。候选失败保留原板；候选通过才小批写入，旧分支按ID及类型确认后删除。写入超时先读回，不重放整批。

两脚器件旋转保留引脚身份与极性。重新导出的pad位置变了就重新生成候选；不要把旧路线仅平移后当作避障仍有效。若多次局部试布都被同一磁件/大电解阻断，记录阻挡和最大外形，改变整个功能组，而不是无限缩小网格。
