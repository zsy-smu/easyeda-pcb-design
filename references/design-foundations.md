# 基础核对怎样落到能工作的PCB

面向实际新板/改板的决策表；完整电气审查与器件依据见[electrical.md](electrical.md)。这些步骤在放件前做，不能让DRC替代。数值用当前准确料号和实际工况计算，不从网名猜规格。

## 1. 先做电源预算与极性图

逐电源轨记录输入最大/最小电压、稳态电流、启动/堵转峰值、持续时间、容许压降；同时列每个接口Pin1/电源/地/方向。航模“12V”只是习惯叫法，必须核电池串数、满电、欠压和瞬态；舵机数量/型号未知就不能宣称某个5A模块足够。

把正向供电和回程画成闭环：输入端→保险→防反→转换器→负载→返回端。串联二极管按`P≈VF×I`核热，LDO按`P≈(VIN−VOUT)×I+VIN×Iq`核热；封装的额定电流不代替结温/铜散热计算。MOS检查实际VGS、导通电阻测试条件、引脚映射和默认上电状态，不因标称电流大就接受。

输出不只看转换器：核模块真实连续功率、端子、MOS、焊盘出口、铜宽、via和地回路的最窄链。暂态电容初估`ΔV≈I×Δt/C+ΔI×ESR`，但不能用无限加电容代替电源能力，也要核浪涌/开关稳定性。

## 2. 去耦不是“放几个100nF”

先列芯片每个电源脚与对应地脚/裸焊盘，给每组标注旁路和本地储能职责。走向检查`电源脚→电容→返回脚/连续参考铜`，减少中间过孔和绕行；不能为了排齐阻容，把C放到离芯片最近但电气路径最远的方向。

模拟电源/参考按手册滤波与取样，不能把VDDA直接漏接或以数字电源标签代替全部物理脚检查。MLCC名义10µF并不等于工作偏压下10µF；电解数据的阻抗、ESR、纹波频率/温度不同，不能互换。先核所用稳压器稳定范围，再决定陶瓷/电解和并联搭配。

## 3. 把Buck/Boost从“连接图”变成“电流环”

分别画开关导通与关断时的路径，标出两种状态之差形成的高di/dt回路。输入旁路、开关/续流、输出储能及返回位置依拓扑与手册布局。SW节点只保留必要连接及面积，不把它当散热地铜铺满；反馈/补偿/采样不要从SW缝隙穿过。

分流采样核Kelvin正负端、参考地与大电流回路；反馈取样核输出实际取点、分压/滤波、FB引脚。线短仍可能取样错误。隔离域看完整供电/信号/机械边界；有光耦但两边共地不能声称隔离。

## 4. MCU能否启动：逐引脚而非凭经验说“最小系统没问题”

检查完整VDD/VSS/VDDA/VSSA、BOOT上电默认态、NRST、SWD脚序、调试器供电方式和板上电源冲突。晶体的近似负载为`CL≈C1×C2/(C1+C2)+Cstray`；准确晶体CL和板寄生决定电容，不统一写22pF/33pF。

有源振荡器与两脚晶体不同：核频率、电源/OE/输出幅值、OSC_IN/OSC_OUT和固件BYPASS；四脚封装大小相同也可能脚位/功能不同。接口RX/TX根据实际信号源/接收端确认命名，5V供电模块不一定是5V逻辑，串联1kΩ不等于电平转换。核具体MCU引脚在当前模式/供电状态的耐压，不能泛称整颗F103都耐5V。

## 5. 机械、库和制造是电气实现的一部分

器件库必须匹配准确料号：符号脚号→封装pad→真实器件脚→PCB网络四者逐一对应。相同封装名可能有不同脚距/孔/焊盘；多个符号单元属于同一芯片，一脚也可能有多块物理焊盘。

最大本体、引线成形、热间隙、插头/螺丝工具空间分别核对。用独立机械要求检查实际Gerber的孔、槽、板框/阻焊；不能只画丝印替代槽，也不能把焊盘框当电感/电解外壳。金属垫片禁铜与板边绝缘按装配状态检查。

## 6. 最小可用的记录与接受顺序

每个关键功能保留一行：`需求/工况 → 准确器件/手册依据 → 真实脚号/网络 → 布局/回流要求 → 当前检查 → 未验证项`。按电气成立、真实脚网、本体可装、关键回路、全板铜连接、原生DRC、制造、交付往返推进。

工具能证明的是具体输入下的逻辑/几何/文件事实；启动、纹波、峰值跌落、温升与EMC需要相应仿真/实测。设计阶段可形成完整可编辑交付，不把缺少实板性能验证混成“连PCB也没完成”，也不能反过来用DRC0承诺实物性能。
