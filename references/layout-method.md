# 布局方法：先让器件能装、关键回路能走，再布通全板

用于新板、重排或“布局很乱”的改板。局部文字修改不启动全板重排。电气选型见 [electrical.md](electrical.md)，几何工具的输入与边界见 [layout-tool.md](layout-tool.md)。

## 1. 把需求转成可摆放的约束

先核清板框/坐标/单位、固定孔、板厚与层叠、接口插拔方向、模块外形、器件最大本体、线束与工具空间。为固定项和可移动项分别建清单；元件数量、板内范围、单位转换先作抽查。原理图转PCB后的横排、竖排和飞线是初始导入状态，不能当作已完成布局。

器件至少区分三种几何，不以一种代替另一种：

| 几何 | 能回答的问题 | 不能据此证明 |
|---|---|---|
| 实体焊盘、孔及铜形状 | 引脚出口、铜距、孔距、短接 | 外壳能装下、插头能插入 |
| 最大本体/可信courtyard | 电解、磁件、端子、开关之间的装配冲突 | 手焊工具、散热片及线束的操作空间 |
| 使用空间包络 | 螺丝头/垫片、调节、插拔、散热器与模块底部 | 电气绝缘或散热性能已实测合格 |

`check_placement_collision.py` 的焊盘外包框只是粗筛，不能由两脚电解的焊盘间距推导圆罐直径；有厂家本体数据时使用显式本体框。旋转矩形先在全局坐标变换四角，再求外包框；垂直器件、极性、定位孔与背面占用单列。相同电位的外壳相碰也可能无法装配。不存在所有元件一律留1mm或1.5mm的通用装配间距。

## 2. 从固定机械点和完整路径开始

1. 放板框、孔、受约束的接插件/按键/指示灯。按真实Pin1、接线入口和外壳校准朝向，再锁定。
2. 电源入口沿“端子→保护→输入电容→转换器→输出电容→负载”安排，并同时画回流。串联防反、保险丝、MOS开关不能因网名不同被分到无关角落。
3. MCU先预留电源脚逃线和去耦位置，再安排时钟、复位/启动、调试。MCU不必位于几何正中心；接口的信号方向和回流更重要。
4. 驱动/功率级靠近负载接口，采样/反馈与开关节点分开。模拟接口、滤波、参考源形成紧凑信号链。
5. 最后放普通上拉、指示灯等低敏感器件。图面整齐是结果，不以把电容排成一行替代对应引脚就近连接。

两排模块插针按一个有固定排距、脚序、朝向和子板包络的整体处理，不能作为互不约束的一串焊盘自动排布。接口往板边摆不等于朝向正确：还要检查插头越界、边缘开口、夹线螺丝和邻近器件。

## 3. 先辨识回路，线宽随后计算

电流必须形成闭合路径。把高di/dt的去程和回程画在同一张局部图中，按芯片参考布局核对实际焊盘。以实际拓扑辨识导通/关断状态，不仅按“输入区、输出区”分组。

| 路径 | 摆放重点 | 常见退化 |
|---|---|---|
| 非同步Buck | 输入旁路、开关管、续流二极管/地的高di/dt换流环路紧凑；电感、输出电容和回流连续；反馈从要求的输出点取样 | 扩大SW铜；二极管或输入电容被挪远；功率回流穿过控制区 |
| Boost | 电感、开关管、二极管及输出电容按两种开关状态识别脉冲环路；驱动与源极回路紧凑 | 高压输出去回程绕大圈；反馈线沿开关节点/高压电容外框绕行 |
| 驱动器/舵机电源 | 驱动器本地旁路，负载供电与地完整承载峰值；控制线有连续参考 | 只加粗正极，地回程/焊盘出口/过孔成唯一细颈；负载冲击造成控制电源跌落 |
| ADC/反馈/电流采样 | 取样点按手册，必要时Kelvin引线；滤波器靠接收端；避开SW和栅极回路 | 采样线与功率线共享有压降的长支路；为绕障把微弱反馈走成长环路 |
| MCU去耦 | 供电脚—电容—回流形成短连接，地端附近有可实际连通的参考铜/过孔 | 电容中心很近，但支线绕行；地孔只接一块悬浮铜 |

不能只用线长判断回路好坏，也不能以“4mm粗线”“双面加锡”宣布脉冲载流合格。检查最窄处、铜厚、过孔、焊盘、连接器、电容端子及热限制；开窗只是阻焊处理，并不自动增加铜厚或确定可重复的锡层截面积。

## 4. 让试布线决定下一次布局修改

在可恢复候选上先走最敏感的几条路径，检查出口、回流和邻网，再铺普通线。不要先自动布满整板，再把反馈线硬塞进剩余缝隙。

- 优先通过旋转两脚器件、调整一个功能组、换一个合理出口来改善路径；不交换极性脚号来迎合布线。
- 局部拥挤时，不连续把器件向同一方向“推几毫米”。重新检查所在区域的二维容量：哪些固定、哪些可向上/下移动、哪些需要转向、整个组是否应迁移。
- 三个器件互相挤压时同时检查三者及邻居的最大外壳，而不只看刚改的两个焊盘。操作后重新检查全板候选，旧的无碰撞结论不能覆盖新坐标。
- 用“未连网络及阻挡对象、关键绕行、回流缺口、最窄处和装配冲突”决定接受与否；布通率或飞线总长度不能压过硬约束。

`optimize_orientation.py` 仅是离散角度、曼哈顿距离和线段交叉的离线建议，不是实际路由器。它不知道高频回流、极性装配、热设计或新角度的所有障碍；建议必须回到真实封装复验。

需要实际几何避障时，可用[固定线宽局部路由](local-routing.md)得到一对焊盘的候选；每条接受后更新障碍。走不通的具体出口/层间空间应反馈布局，不能靠自动降宽蒙混。需要完整故障处理过程时读[联合布局和反馈案例](worked-failures.md#6-u3l1c3右移后又压住r20c1盖住tp1f2)。

## 5. 换层、地孔和铺铜要落到实体铜

顶/底层走线跨越可以避免同层交叉，但通孔焊盘及镀孔铜筒连通两面：移到底层后，仍必须绕开异网通孔和其环铜。不能把“整条负极换到底层”当作一切短路的通用修复，也不能通过切断正极使短路报告消失。

判定相交时使用网络、实际层及有宽度的铜形状，叠加焊盘、过孔与已生成铜区；红/蓝截图只作定位。检查两面是否靠真实同网镀孔衔接，不按网名把几块断开的铜强行合并。

地孔优先服务可说明的连接：去耦回流、层间参考转换、功率返回、屏蔽/连接器地。依据焊盘、钻孔、铜距、隔离与天线禁布安排，不做无目的均匀撒孔。孔数增加不证明噪声、EMC或载流已改善。

重建受影响的铜区后再检查连通与浮岛。独立实心FILL不一定参与EDA自动重铺铜；交付时说明是否需脚本重建。铜边退让、螺丝垫片禁铜、开槽与隔离域按本板要求设置，不能照抄历史尺寸。

现有[地铜生成器](ground-tool.md)把孔洞无损分成实心区域，并用真实锚点筛候选；[实际Gerber铜检查](copper-tool.md)再对输出检验逐焊盘覆盖、真实PTH跨层、短/断及NC。两个阶段不能互相代替。

## 6. 每个候选应能回答的验收问题

- 最大本体、手焊/插拔空间及孔位是否可用？焊盘无冲突还不够。
- 指定引脚之间是否实际布通，关键回路是否紧凑且有返回路径？
- 增宽/换层有没有碰到异网焊盘，是否引入唯一细颈或不合理过孔？
- 所有层的铜、孔、阻焊开窗和铣槽是否在实际制造输出里存在？
- 原理图、PCB、BOM、最终工程包及重开后的当前板，是否属于同一版本？见 [交付往返验收](handoff-roundtrip.md)。

## 7. 本轮反复遇到的问题，下一次怎样直接处理

| 现象 | 先读的真实数据 | 候选动作 | 接受条件 |
|---|---|---|---|
| 电感、电解和旁边小电阻同时挤压 | 三者最大本体、真实焊盘、下方接口及相邻固定件；不是只读中心坐标 | 联合选择不同Y位置/旋转/功能组位置，保留功率路径；必要时回调前一个器件 | 全部本体和操作空间满足，输入/续流/输出回路没有被拉长到不可接受 |
| MCU边上阻容“很整齐”但引脚被压住 | 旋转后的每个焊盘、IC脚距、去耦对应的VDD/VSS、实际走线 | 按供电脚分别放旁路，给引脚逃线留走廊，普通上拉/指示阻容移到较不敏感空位 | 每个器件能安装；对应脚—电容—回流路径短且真实接通，未用相邻IC焊盘穿线 |
| 反馈线围着大电容绕一圈 | FB脚、分压/滤波节点、规定取样点、SW/驱动和地回流铜 | 把反馈组放到接收端附近并走避开开关噪声的直接路径；需要时先重排功率级 | 线短只是条件之一；取样点、参考及滤波关系正确，不靠近高dv/dt节点 |
| 粗线到了焊盘突然变细 | 主干到端子的每段、热焊辐条、过孔环铜/钻孔、焊盘出口 | 在允许空间内局部增宽或改变入射方向；按容量核过孔并联与端子 | 最窄链条与热条件有依据；不能只靠给主干加锡或把线宽显示得更大 |
| 移到底层后仍有高压短路 | 两面铜、每个异网通孔、镀桶及实际开窗 | 改整条受影响路径并绕开异网PTH，不仅改变一段颜色；正极保持完整连接 | 同层异网不相交，跨层通过真实同网过孔连通；所有关键焊盘端到端接通 |
| 一半板红、一半板黑 | 活动/隐藏层、实际FILL/POURED范围、该铜的网络与隔离边界 | 先分层显示/读数据；只在电路要求的返回区补铜 | 黑色不能单独证明漏铺，红色不能单独证明接地；无浮岛/隔离越界，关键回流连续 |
| “开窗/铣槽在图上有”但制造文件没有 | 本版LAYER语义、对象类型、实际GTS/GBS/GKO/钻孔文件 | 按导出器支持的对象创建并导出；逐一对比预期形状 | 真正制造层存在相应区域/槽，不能以装配层画线或截图代替 |

这些是排障路径，不是预设坐标。新器件的最大尺寸、封装版本与实际方向不同，就从真实数据重新算，而不是重放上次板的坐标脚本。
