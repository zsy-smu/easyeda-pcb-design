# 原理图与连接保持

## 建立电路再安排图面

按真实料号查库，核对符号引脚号、功能、封装焊盘号和采购属性。同名器件不保证映射相同，不凭图标上下左右判断极性。

复用电路块时检查电压、电流、启动条件、参数、封装和布局约束；通过过 DRC 的模块仍需适配本次用途。

按信号流和功能组织图面：输入到处理到输出，电源通常在上、地在下；电源、核心、时钟/复位、模拟、通信和负载分别成组。小图不必拆很多页，大图可功能分页。

设计时维护一份“完整料号/封装 → 位号与物理脚号 → 引脚功能 → 网络 → 外部接口”的对应关系，供原理图、PCB、BOM和固件接口表共同使用。器件与封装变化要同步核对该表，避免正文、图纸和代码使用不同GPIO或针序。用图形排版替代不了这份逐脚对应。

开始大图前确认纸框实际边界、原点和坐标方向，给模块及注释留空间。只换更大纸型未必覆盖原点另一侧的内容；避免画完后才依赖未经验证的全页平移 API 修正。

- 模块内部优先短正交线；跨模块/页使用命名端口，避免贯穿整页的长线。
- 电源/地符号和信号端口按其语义使用。普通文字不是电气标签。
- 去耦画在相应电源域旁；原理图坐标不代替 PCB 距离约束。
- 读回网标附着点、导线端点和引脚锚点。线经过无关引脚可能自动接入；交叉是否连通以网表判断。
- 重复网标并非必然错误，以清晰为准；不要仅为删重复文字破坏有用网络名。
- 未用引脚先判断能否悬空再加 NC。网表缺项不等于已审查 NC，不能把所有空网名合成同一网。

## 功能分区与重复通道

用户提供的网关、农业终端和多通道接收板图面可作为排版参考，来源与边界见 [参考图记录](sources.md#用户提供的参考图2026-09-06)。

- 多模块同页时，可用有标题的图形框或分隔线组织电源、控制核心、通信和外设。框线使用非电气图形，不用导线充当边框；标题不覆盖器件或电源标记。
- 先分配模块区域和标题栏位置，再放器件。区域大小由内容决定，不为等分格子挤小文字；整页适配视图能辨认模块，局部查看能读清位号、参数与网名。留白集中在模块之间，避免一边拥挤、一边大片空白。
- 核心控制器可作为图面的阅读中心，外围按功能组织；是否在 PCB 中央由接口与物理回路决定，原理图分框不是 PCB 坐标约束。
- 重复通道使用一致的器件朝向、局部连接形状、文字位置与间距，按通道号排列。复制后逐路核对独立信号网、位号、控制器引脚和有意共享的电源/地，不能把两路信号因标签重名合并。
- 桥式功率电路可按左右桥臂成对表示，把驱动、开关、输出和采样关系画清；辅助控制另成组。借鉴阅读顺序，不从对称外观认定门极映射、电流方向或采样接法正确。

## 整理已连线的图

保存器件稳定 ID/位号、引脚到网、显式 NC、器件值、库 UUID、封装与 BOM 属性。缺少可靠全页读回时先补读取能力，不能凭画布建立基线。

比较时防止两种误判：

- 同名网络成员也可能变化；比较完整引脚集合，指出具体新增/丢失的引脚。
- 自动网名变化但引脚分组不变，未必改了电路。以引脚集合构成连通分区，另查有意义的信号名/电源名。仅规范化经核实的别名。

纯排版要求连通分区、NC 和电气属性不变；实质电路修改对照目标差异，不能要求旧网表完全相同。

优先使用当前版本验证过的整体移动，将器件、局部线、标签一并移动。需拆线重连时先记录逐脚目标，局部完成并读回后再做下一块。不要在有线页面套用仅适合空白页的全自动排布。

共享导线的子组应整体处理或显式管理边界。移动中注意新旧导线意外合并；临时移到远处必须处理边界和中间状态，不作为通用快捷方式。

## 核验

每批核对连接变化是否符合目标，无无关 Junction/孤立端点/电源误接；其他元件及 BOM/封装保持，位号和稳定 ID 未被悄悄重建。检查标签、器件、功能框、图框是否遮挡，导线是否穿无关器件。

完成后执行可用原生 ERC/DRC、连通检查并保存。只有布尔结果时记录检查种类和范围；错误读取具体项目，警告审阅后报告。

同步 PCB 前审查新增/删除/封装/网络差异和板关联；等导入真正完成后重新读回引脚、封装和网表。“已发起”不等于“已应用”。

格式适配后使用 [网表工具](netlist-tool.md) 保留具体差异报告；比较NC需要实际NC证据。同脚多块实体焊盘不可在PCB核验中去重，仅逻辑pinInfoMap不能证明每块焊盘均存在且接通。两侧实体清单存在时比较数量，再由实际铜和原生规则验证连接。
