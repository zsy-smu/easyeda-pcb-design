# PCB 布局与验证

按当前任务读取相关段落：新板先确定约束、分区和关键回路；已有板先保存基线，再做局部修改与复验。接口、单位和保存异常查 [原生几何](native-geometry.md)；换件及归档对应查 [器件替换与交付](replacement-and-delivery.md)。

## 1. 先确定设计依据与固定项

记录板框、层数/叠层、铜厚、安装孔、接口方向、机械禁布、供电与负载、压降/温升目标、关键时钟/模拟路径及必要阻抗要求。每项注明来源、固定或可调整、验收方法及当前状态；可用表格、JSON 或项目已有格式，不把自定义字段当成 EDA 已支持的规则。

有适配输入时，把工具已支持的要求交给 [布局合同检查器](layout-tool.md)。它检查矩形板框、全局包络、位置/面/朝向、器件禁布与点间直线距离。接口方向须由实际封装校准，点间距离不证明走线长度或回流；不能把上游工具的默认间距直接当作本板要求。

- 以最新已确认需求和实际原理图为准。供电专用 USB 不增加数据布线要求；采用内部时钟的板不套用外部晶振布局。未知负载电流保持待定，不能由现有线宽反推额定电流。
- 区分电压相同但电气上不同的网络，例如稳压器前后电源、受控负端与 GND。多个输出端子共用的电源能力不按端子数量重复计算。
- 固定机械锚点、关键连接和已通过的硬约束应随候选保存。试布线不能悄悄移动接口、减小间距或改变层数来取得更高布通率。
- 规则值来自本次器件、制造能力、电流和叠层；声明但未检查的要求仍未验证。旧板的尺寸、过孔规格、线宽和算法网格不作为新项目默认值。

## 2. 从拓扑和机械锚点安排布局

先放板框、安装孔和受机构约束的接口，再安排电源入口、保护、转换、负载与回流。按完整路径分组，不仅按相同网名聚类：串联电阻、磁珠两侧虽然换网名，仍属于同一路径；旁路与 ESD 支路不能误当串联节点。

机械检查采用当前实际封装与厂家图纸：

- 核对插线/插头入口、Pin 1、极性、外壳伸出及板料干涉；封装零度不等于接口朝上。旋转后按实际焊盘重算，不凭丝印外观猜方向。
- 给螺丝头、螺丝刀、接线弯曲、插拔、拨码和电位器调节留空间。可更换保险丝、散热器及手焊位置也要能接近；“焊盘不重叠”不证明可装配。
- 核心板两排排针作为固定孔距、脚序和朝向的整体，计入子板底面元件、支撑件与绝缘空间。模块四角的孔可能兼作电源端，不能全部认作接地安装孔。
- 检查完整封装的本体、定位孔、槽孔、板框层和禁布图元。只读 PAD/REGION 会漏掉部分封装子图元；通用矩形或未校准偏移的 3D 模型只能初筛。

沉板接口的槽口与制造间距冲突时，先核对真实外壳和推荐开口。不能为清 DRC 缩槽或放宽全板规则；在当前授权和接口要求允许时，选择有依据的兼容器件，并同步原理图、PCB、BOM、局部走线及参考地。见 [机械替换](replacement-and-delivery.md#机械冲突与器件替换)。

含 PCB 天线的模块另列禁布约束，按该模块资料检查相关铜层、器件和金属外壳；照片上的开槽不能证明合规。ESP8266 的示例依据见 [乐鑫硬件指南 §1.6.2](https://documentation.espressif.com/esp8266_hardware_design_guidelines_en.html)，不把其间距套用到其它模块。

## 3. 先安排关键回路，再填普通器件

| 路径 | 摆放与检查重点 |
|---|---|
| MCU 供电与去耦 | 每组电容对应实际供电脚，检查电源脚—电容—回流的完整连接；电容中心很近但绕线很长仍需调整。为逃线及接地过孔留位置。 |
| 晶振与模拟采集 | 围绕对应引脚紧凑摆放晶体/负载电容或输入滤波；检查真实路线和回流，避免无关信号穿行。无过孔但长距离绕板也不算短回路。 |
| USB 等成对信号 | 根据器件手册安排接口、保护和串联器件；结合真实焊盘让两根线成对通过，检查参考层与换层位置。两根各自布通不等于差分路径合格。 |
| 开关电源与电机 | 先辨识输入脉冲回路、开关节点、输出回路、反馈取样及功率回流；把相关电容/器件作为整体安排。不能为了“大面积铜”无目的扩大开关节点。 |

热焊盘、散热片连接和大面积引脚先查实际网络；例如稳压器散热焊盘可能接输出，不能默认都接地。保护器件、连接器和负载的布局应保留完整去程与回程，避免让 MCU/ADC 的局部回流承担负载电流。

## 4. 层数、参考平面和网络规则一起决定

层数根据封装逃线、布线密度、参考连续性、电源分配、隔离和成本确定。两层板与多层板不照抄同一铺铜顺序；多加一层铜也不自动解决不合理布局。需要受控阻抗时，先有制造叠层及其计算依据，再定线宽/间距；单凭预览不承诺阻抗或 EMC。

- 为关键线指定参考层，检查走线投影、要求的外侧余量以及参考铜到地锚点的实际连接。电源区域、异网过孔避让和机械开口都可能切断参考。
- PGND、GND、AGND 的连接遵循电路的回流与明确连接点；不因名称不同就任意割地，也不因都叫“地”就合网。隔离侧电源和地保持各自边界，逐层检查铜和过孔是否越界。
- 禁布要区分禁止器件、线、过孔和铺铜，并核对实际层及规则类型；画了边界不等于该对象受约束。
- 电源使用线、铜区或平面，依据电流、长度、铜厚、温升、压降与回流。检查端子、保护器件、焊盘颈部、过孔阵列和热焊盘辐条组成的整条链；主干很宽不能补偿唯一细颈。

## 5. 用试布线修正布局

在可恢复候选上，先布对布局敏感的时钟、成对信号、去耦和功率回路，再试普通信号。只使用当前已验证的路由能力；不要声称已有脚本支持阻抗求解、差分成对或铜区参与寻路，除非实际验证过这些功能。

失败时记录具体网络、阻挡焊盘/孔/铜、所需出口及已有硬约束。先判断能否局部改线，再判断是否要移动电容、串阻或整个功能组；明确的布局瓶颈不靠反复换网格和降低规则解决。比较断网、关键路径长度/绕行、线宽与回流，不只比较剩余网数。

接受候选前，把局部结果放回最新全板基线检查。其他区域移动过，旧候选的“无冲突”就不能直接沿用。保留已经验证的关键回路；确需改变时重新核验，不能为布普通线退化它们。细间距逃线按真实空间判断何处能加宽，并报告窄段宽度及长度。

需要沿用文件检查结果时，可用 [证据时效工具](evidence-tool.md) 判断其输入和范围是否仍有效。工具无法证明未记录的 GUI 内存状态；读回或原生文件已变化时先更新相关检查，不从当前文件重新计算一个哈希贴到旧 PASS 上。

## 6. 铜、过孔与可焊性

电源连接既查连通，也查实际通路宽度和回流。不要让主电流依靠电解电容引脚的镀孔偶然换层；需要换层时明确设计连接与过孔。热焊盘的直连/热隔离、辐条和热过孔兼顾载流、散热及预定焊接工艺，不能只看铺铜外观。

- 过孔以实际孔径、铜环、层、孔偏移和阻焊设置检查。孔到 SMD 铜的制造检查包含同网焊盘；同网不代表允许钻伤焊盘。槽孔方向按真实孔几何，不能只用器件或焊盘角度代替。
- 盖油、开窗、塞孔等工艺不混用。API 中空值可能跟随规则，不能据它宣布盖油；属于交付范围时核对最终阻焊文件。手焊热容量与焊点可达性也需单独检查。
- 泪滴按工艺需要采用，不是每板必选，也不代替线宽、铜环和间距。原生功能尚未验证时说明边界；普通同网 FILL 过渡不能冒充自动维护的原生泪滴。增加后仍检查实际相交、网络、图层及邻网/阻焊空间。

铺铜先安排有明确用途的区域，再安排周围参考地；重叠优先级按当前 API 和读回语义验证，不能假定数字越大越优先。器件或线路改动后重建相关铜，检查实际填充、热连接、孤岛及颈部。

POUR 边界不是实铜。验收要包含 POURED 的孔洞、圆弧和热连接，以及独立 FILL、焊盘、线与过孔；空孔保留为空孔。参考缺口按实际断口、异网避让或接地过孔钻孔分别定位，不统一忽略，也不把物理孔内无铜误判为环铜无回流。详细方法见 [实际参考地](replacement-and-delivery.md#实际参考地与补充填充)。

## 7. 丝印、装配图与局部复验

极性、Pin 1、电压、受控端和接口名称对应真实引脚，正常装配后仍需可见的文字放在壳体外。模块覆盖的说明可保留作装配前标记，但不替代外侧接线标识。密集区先保持标签归属清楚；必要时用短引线、底层丝印或装配图，不把位号放进无关空白。

实际字体、阻焊开窗、孔和板边都参与检查。不要把枚举到的隐藏属性全部显示；底层字按真实底面观察检查，不能只凭 mirror 布尔值或顶视预览判断正反。3D、近似字框和生成成功的图片均各有边界，应实际查看输出。

| 局部改动 | 必须复验的关联对象 |
|---|---|
| 端子旋转、器件移动/替换 | 实体焊盘与引脚网络、壳体/工具空间、孔与板框、相连走线、极性/位号、受影响铺铜；替换还需同步库与 BOM。 |
| 去耦、时钟、电源局部调整 | 指定引脚的完整回路、逃线、过孔孔距、邻网、参考层；检查其它已通过关键路径没有退化。 |
| 加宽、换层、增加铜区/过孔 | 实际连通、最窄路径、异网/机械间距、参考和隔离域、热连接及阻焊；重建相关铺铜。 |
| 仅丝印或显示属性变化 | 可见性、归属、阅读方向和持久化；证明电气/几何记录未变后沿用对应电气证据，不为文字修正重布全板。 |

## 8. 以最终实际板完成交付

网表一致证明网络分配，不证明铜已连接。原生连通/未连接及 DRC 与独立检查相互补充；独立算法明确支持的孔型、弧、旋转/镜像、多边形与铜类型。不能忽略未知对象再报全板通过，也不能用焊盘外包矩形的相交代替实际铜接触。

原生可能拆分/合并同网线段、换 ID 或量化坐标。以最终网络、层和真实几何证明等价或明确变更，不能要求操作条数等于最终对象数，更不能删除陌生 ID。单位和精度问题只按当前证据局部处理，见 [原生几何](native-geometry.md)。

完成当前范围的检查后保存，并交付同一版本的工程、制造文件、BOM、接口表、装配/铜预览及简明验证记录：

- 原生 DRC 对应当前源与重建后的铜；PCB、SCH 和实板验证分别报告。布尔失败无明细时保持原因未知，不引用历史警告解释本次结果。
- 板框需被实际导出器识别。取得真实 Gerber ZIP 后核对板框、所需层和逐孔几何；“返回 File 成功”不等于已取回或检查文件。
- 完整工程含本次页和库引用；单页源、JSON 快照或数据渲染图不能冒充完整工程、原生截图或制造文件。预览显示实际铜，并注明观察方向及未渲染内容。
- 比较保存、归档和导出所代表的版本，更新当前 BOM、清单与入口，旧候选明确标作历史。关键检查通过且无新变化后结束重复审计；未做的负载/温升/EMC 实测单列。

可复用 [网表工具](netlist-tool.md)、[制造文件工具](manufacturing-tool.md) 和 [交付文件清单工具](delivery-tool.md)。它们各按输入契约核对文件，不替代原生设计、完整铜求解或功能审查；哈希清单只冻结文件字节。归档身份、重复焊盘号及导出核对见 [交付核对](replacement-and-delivery.md#保存导出与明确交付)。
